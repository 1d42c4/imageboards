# Project notice

Chessboard Lite is an independently structured application inspired by familiar imageboard posting and moderation workflows. It does not bundle a legacy PHP framework, Twig, Composer packages, jQuery, Node.js modules, or third-party runtime libraries.

The optional Traditional theme group maps colors and small local background strips from the stylesheet reference archive supplied by the operator onto Chessboard Lite's own CSS variables and selectors. No legacy application code or remote assets are included.

Keep the original reference archive and its notices intact if you separately distribute or modify that original material.
